# WHOLE NETWORK WEAVE 002 — WAKE × invitation chain × sovereign organs

**Status:** user-requested executable **local** prototype, stacked on JAR;VIS WAKE Signal PR #69. Does not deploy, enroll a partner, read a private source, or transfer authority to another app.

## The compositional loop

\`\`\`
source-labelled / operator-authored opportunity
  -> network atlas / thematic receiver candidates (not real matching)
  -> JAR;VIS Any Invitation 001  (act / offer / ask / pass / fork / decline)
  -> exact pinned MOTIF WAKE 001  (SMALL / CREATIVE / AUTONOMOUS)
  -> human chooses to send to consenting recipient, separately
  -> operator-attested response/action/unplanned action
  -> manually reviewed fork with parent lineage, or portable unsigned carrier
  -> independent receiving room: HOLD, inspect, optional NEW LOCAL DRAFT
\`\`\`

We compose existing implementations rather than replacing Garden, The Seventh Table, NOW-ROUTE, Commons, reLATTE, Jubilee, Static OS, GHoT, Free Graph, or Full Measure. The atlas includes 15 distinct contexts and source owners; a conceptual adjacency is **not** a working API connection or established human relationship. All source links are descriptive; neither GitHub nor Supabase nor anyone's personal accounts are contacted by the runtime.

## What actually crosses

A local operator can type a public-safe, bounded opportunity, select a source context from the atlas, preview reuse/recipient candidates, and **explicitly** create a MOTIF WAKE study. A checked preview SHA ensures the words reviewed are the exact words stored; missing approval HOLDs. A parent-child fork is permitted only after the parent WAKE study has an operator-attested \`novel_action\` on that exact slot, preserving that **a report is not proof**.

The original JAR;VIS \`any-invitation-001\` cartridge supplies ACT, OFFER, QUESTION, PASS, FORK, DECLINE action proposals and respects stated availability. Those are local choices only, not dispatched operations.

A human may approve the public-safe export of an **unsigned portable carrier** addressed to one named *organ type*. Another JAR;VIS instance can paste it, validate its exact SHA and packet schema, HOLD it, and only after independent review make a **new unverified WAKE draft**. This is genuine file/text portability, not account authentication, network synchronization, third-party publication, or source-owner ADMIT.

The weave's own hash-chained local journal records **only source node, desired target node, parent study/slot, packet hash and local study ID**. Separately approved receiving drafts record the foreign source node and origin study ID as **untrusted claimed ancestry**, never authenticated identity or local parent authority. Raw operator words live in the separate WAKE local study; no people names or contacts are stored by WEAVE. The journal is unsigned, local, not tamperproof or multiparty transactional. WEAVE does not join source-owned databases.

## Source boundaries observed

- **Garden / BananaSpork**: main README describes Help Slip HOLD→review→POUR, shared Campfire and distinct confirmation. Its actual membership database is not imported.
- **The Seventh Table**: the up-to-two invitation/ambassador model lives in **unmerged webZ PR #121**. WEAVE links to the branch; it does not claim enrollment, public deployment, or perform Seven-Day Table operations.
- **NOW-ROUTE 003**: the project describes a deployed invite-only Edge Function with testable shelf-stable matching and a two-person handoff protocol; **JAR;VIS PR #55 is unmerged** and field proof of a real handoff is absent. Perishables and private locations remain excluded.
- **Commons**: the main source describes a public admitted-only room and separately HELD submissions; the code here never submits to it or invokes a model.
- **reLATTE**: sovereign signed crossings are separate from copied SHA checksums; WEAVE's carriers make no signature or identity claim.
- **Jubilee / Book of Acts**: only independently confirmed actual outcomes may be considered for later human review. Operator-attested WAKE actions are not Book of Acts evidence by themselves.
- **Static OS / GHoT / Free Graph / MEMENTO / Full Measure**: capability, graph relation, media/world state and remembered tradition are not permission to run devices, target people, or publish.
- **Fellowship / Coalition of Care**: human-context nodes only; no institutional seat or partner authority is assumed.

## Local steps

\`\`\`sh
npm test
npm start
# open http://127.0.0.1:7789/weave
\`\`\`

Start a preview with an *illustrative* Fellowship, Garden or Commons scenario, then create a local WAKE study only after reviewing wording. Use \`/wake\` to record consent-gated manual outcomes. To fork, go back to \`/weave\`, select a locally recorded \`novel_action\` slot and explicitly provide a new opportunity. Export an unsigned JSON HOLD carrier to a separately reviewed receiving desk; the receiving desk can make a new draft with no real-world verification.

No phone-number scraping, automatic outreach, eligibility/mental-state scoring, identity inference, relationship ranking, service-need disclosure, or opt-out circumvention. A person does not have to use this software to participate.

**Research question:** Which specific invitation conditions make new voluntary, useful actions possible across independently owned networks? The prototype records a pathway; **no causal field outcome has been established**.

## Remaining proof

An independently consented, real-world invitation and a verified follow-through, plus review of the receiving room's actual requirements. This local prototype has no live data import or receiver integration. Future transport must be source-specific and separately authorized.
