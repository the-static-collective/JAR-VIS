## What the code does

On the explicit source-inspection POST, JAR;VIS verifies all four local Source Council files against Git's original immutable blob hashes (the originals: motif/__init__.py, branch_garden.py, branch_source.py, source_council.py). It starts a short-lived, isolated-mode Python program through a fixed code path; never runs a user-selected branch program. The Python program creates an ephemeral Git directory, hard-codes the public origin https://github.com/the-static-collective/MOTIF.git and invokes the real original Source Council. The original code enumerates all currently visible remote branch heads, filters a bounded 1–3 shortlist based on the operator's question, fetches exact observed commits, and reads at most four candidate design documents per branch, noting document-term matches and source receipts. The council code is genuinely executed, but code taken from unmerged experimental branches is only **read as inert source**.

**Privacy:** query text is never placed in the Git command, URL or network request. Git only sees the fixed public repository and public branch references. The optional structured reasoning case is not included in any Source Council transport. The resulting response returns to this local machine, is rendered in the tab, and isn't stored in the JAR journal. Loading the UI or GET source-state endpoints causes no network read.

**Authority:** branch labels and claimed docs are untrusted. The original Source Council performs *lexical evidence-oriented retrieval*, not semantic model matching, proof of competence or automated algorithm invention. A visible test file is not evidence that a test passed. A matching doc does not establish a working method. All candidate dispositions remain HELD; no external actions, Git writes, model-weight updates, code imports, approvals or merges occur.

**Resources:** Node limits query to 3–180 printable characters and 1–3 branches, hashes original code, passes bounded JSON into Python with no inherited credentials, and caps runtime/output. Python disables Git global/system config and non-HTTPS transport, uses a literal source URL, and discards the temporary Git objects after the request. Not an OS-level sandbox, and not suitable for executing untrusted research code. MOTIF's separately reviewed Docker runner exists for explicitly approved original tests.
