# JAR;VIS — THE LOST MINUTE POST OFFICE

**A genuinely new creative-production brief**, not the existing Genesis remix.

A fantastical government office returns mislaid minutes of attention to their owners. One returned minute can become a small act of listening, helping, or noticing. The user can watch an original experimental microfilm, receive three printable fictitious "minute stamps", and run a private, accessible 60-second timer. The experience asks for **no account, personal data, tracking, consent of third parties, engagement streaks or public posting**.

## Creative challenge / full finish criterion

An unfamiliar concept must enter JAR;VIS as a free-text objective, be converted into a bounded typed plan by the **original planZ** source, go into the **original CANNON** source, generate real **new** moving/audio native films from original postcard art, have the **original Haunted Toaster** render both videos and issue original video receipts and **Dogram**, return that evidence to planZ and JAR;VIS, undergo a native video revision, then pass to the **original lemonPRESS** for a self-contained interactive/printable kit, undergo editorial evidence review and revision, and be produced as a locally playable ZIP-ready artifact. These are **real source owners**—not names in a decorative plan.

The previous six-repo Genesis production experiment could not accept this new brief. Its original planZ compiler explicitly requires `GENESIS-RETURN-001`. Hosted tests demonstrate that it correctly **HOLDs** the new objective rather than inventing compatibility. The new source-owning planZ PR #41 supplies a **bounded idea-to-four-phase adapter**. Its concept choices are deterministic keyword routing from a human-authored premise; JAR;VIS **does not** invoke a generative model or claim spontaneous artistic ideation.

## Four real sequential loops

1. **Round 0:** JAR;VIS gives planZ the novel premise. planZ compiles a 6-second `PROOF_FILM` with a short visual title. CANNON generates a new image and two-tone original synth audio, invokes **original Haunted Toaster** native scored rendering, verifies original video receipt and Dogram. JAR;VIS returns exact SHA-256 of the actual proof to planZ.
2. **Round 1:** Only if proof source evidence verifies does planZ compile a **different ten-second `REVISED_FILM`** with an explicit practical action and different notes. CANNON renders it through original Haunted Toaster again. JAR;VIS independently cold verifies the actual source media and Toaster's original MP4/Dogram.
3. **Round 2:** With both authentic video/source receipts, original lemonPRESS composes a draft kit: responsive HTML with an offline nontracking 60-second timer, interactive start/stop, source-linked native video, printable SVG stamps and a readable note.
4. **Round 3:** JAR;VIS checks both actual MP4 bytes, original source hashes, draft HTML and original lemonPRESS draft receipt; it returns source-bound revision feedback. Original lemonPRESS **must refuse** to create its revised final kit if that feedback is absent. It then produces revised HTML/letter/stamps with original house receipt. JAR;VIS verifies all original stages and assembles a final local archive.

Source owners: `the-static-collective/JAR-VIS`, `planZ`, `CANNON`, `the-haunted-toaster`, `lemonPRESS` (**5 repositories**). Dogram is a **native part of Haunted Toaster**, not falsely counted as a separate repo.

## New capability versus reuse

The **new original visual and audio** are created from this premise in CANNON, with the planner's exact subtitle lines and a newly synthesized two-tone musical bed. The original Haunted Toaster engine renders them, so the result is **not the existing Genesis footage** with a new title overlaid. The original planning/feedback/artifact delivery engine is constrained and tested. The two distinct renders have different durations, textual content, tonal frequencies, native MP4 SHA-256 and Dogram.

The previous Genesis *Video Pantry* path wasn't generalized as an arbitrary script-to-Remotion adapter; such a claim would be false. Instead this iteration uses the already proven **native Toaster image + audio input**, with an explicit new original CANNON image/audio producer. This is a narrow real bridge helping the system complete the previously incompatible task.

## Finished artifact

A local package with `index.html`, a playable original and revised film, an original lemonPRESS final HTML post office (`kit-final/index.html`), printer-friendly `minute-stamps.svg`, a readable `letter.md`, both original native video/Dogram receipts, an exact four-plan/four-return/four-confirmation ledger, original source-owner Git commit/blob pins, and a final machine-readable manifest. The HTML timer runs entirely in the browser. There is **no network endpoint, account or local/remote data logging**.

## What success does—and does not—prove

- **Proves if native integration is GREEN:** JAR;VIS can turn a previously unhandled creative objective into a real novel source-owned audiovisual artifact, adapt a missing producer interface, conduct two evidence-linked machine rendering phases and an editorial revision, and finish an inspectable useful local media experience.
- **Does not prove:** LLM creative autonomy, unrestricted planning across all repositories, full-resolution cinema, successful real-world help, people saved time, independent human evaluation, social sharing, legal media licensing, recurring background operation, publication or a real post office.

All GitHub PRs are drafts, with no automatic merge or deployment. The end product is strictly local and review-held. A failed original native CI must be reported as a failure, even when the source-owned planning compiler passes.
