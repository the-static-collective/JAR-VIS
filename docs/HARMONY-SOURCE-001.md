# Harmony Source Reader 001 — public-only, operator-initiated

`npm run harmony -- food` reads the **public webZ** Harmony manifest from a fixed raw GitHub URL, validates its eight exact mission profiles and internal relative tool paths, hashes the source bytes and emits one `jarvis.harmony-candidate/v1` **HOLD_FOR_OPERATOR_REVIEW** JSON candidate.

This is a working read-only adapter into an already independently owned tool. It does not access Google Drive, import private research, transmit visitor questions, contact a partner, execute a module, create a plan, modify GitHub state or grant JAR;VIS authority over webZ.

Available contexts: food, fellowship, campus, festival, care, farm, civic, founder.

Fail closed on unavailable/redirected sources, unexpected content types, too-large documents, invalid profile IDs, new destination URLs, changed authority statuses, or malformed JSON. The fixed manifest is a public editorial synthesis, not verified organizational information or human consent.

A later project-owned integration may let planZ review the candidate, GRAFT pin a public source revision, or STATIC OS include the selected offline tools. Each requires a separate receipt and authorization. For now the runtime strictly reports candidate status with a source digest and does no other work.
