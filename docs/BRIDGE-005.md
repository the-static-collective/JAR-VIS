# JAR;VIS BRIDGE-005 — Independent local receiver

The owner may manually download a public-only `abundent.bridge-work-card/v1` from Abundent's Bridge desk. Run `npm start`, open `http://127.0.0.1:7789/bridge` and choose the file. This loopback UI uses the existing CSRF-protected server, checks exact pinned source commit, expected receiver `JARVIS`, closed institutional/action identifiers and SHA-256 integrity, then returns `HOLD_FOR_OPERATOR_REVIEW`. It does not import private journal data, run models, send messages, grant authority, authenticate operators or institutions, or publish outcomes. The digest is not a signature. Source protocol: https://github.com/the-static-collective/webZ/blob/main/docs/BRIDGE-005.md . The full contract is `src/bridge-work-card.mjs`; tests are `test/bridge-work-card.test.mjs`.
