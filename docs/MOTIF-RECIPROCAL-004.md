# JAR;VIS public MOTIF reciprocal donor (004)

**Source:** public `the-static-collective/MOTIF`, exact pinned commit `efb9fe46ebad1b0fc1da91bd7834b7c9fac00707`, `experiments/reciprocal-004/capability-passport.v1.json`. It is a known unmerged research branch; the reader does not assume `main` contains this work.

## Why attach it?

MOTIF's reciprocal research has two human entrances: **Ask MOTIF** and **Let MOTIF ask**. A bounded question controller can compare explicitly entered source claims, preview speculative answers, and propose a held conditional method. JAR;VIS can now inspect a *public description of those research abilities* without taking ownership of the model, underlying data or people.

Run:

```sh
npm run motif:inspect
```

It performs a **single operator-requested, exact-SHA public GET**, validates the public capability passport, records source SHA-256 and observation time, and returns three inspected **non-callable** research capacities plus twelve **proposed, not connected** neighboring doors. No user query or raw human answer leaves JAR;VIS. The response has `admission:none`, `executionAllowed:false`, `externalActions:false` and `HOLD_FOR_OPERATOR_REVIEW`.

## Hard boundaries

The donor file is *not* an execution-capability token, an authenticated source of real answers, an active neural model, or a production JAR;VIS feature. The read-only operator CLI cannot ask another person a question, install cartridges, call MOTIF reasoning, admit a claim, write a source repository, contact someone, or send data to the Commons/Supabase. A reflected public repo name is strictly allowlisted; extra foreign commands/fields are discarded.

Local deterministic tests use an exact public synthetic contract fixture; CI also performs an actual pinned GET, source-bounded check and downloadable source observation. Failed fetch, altered schema, active authority claim, unrecognized capability, extra neighbor, wrong content type and malicious redirects fail closed. No production deployment occurs. The prior draft MOTIF RECIPROCAL-004 source `PR #325` remains owner-controlled.

## Subsequent reviewed development

A separate owner-approved JAR;VIS receiver could render the *source-reviewed synthetic graph* (without raw participant data), or host a consented local Two Doors UI. Actual shared public participation needs protected intake, withdrawal, rate limits, independent source-provenance checks and moderation. This PR deliberately does not take that step.

**Source document ≠ machine runtime; shared vocabulary ≠ permission; research result ≠ user outcome.**
