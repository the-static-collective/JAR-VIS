## The strange little machine

The original [MADD CLOWN CRAZY SLOTS design](https://github.com/the-static-collective/the-haunted-toaster/blob/main/docs/superpowers/specs/2026-09-15-madd-clown-crazy-slots-design.md) establishes an important authority split: **focus != verdict; KEEP = exact continuation permission; SCRAPE = family extinction without universal feature dislike; the machine chooses how to breed.** We adapt that law as a separately implemented **JAR;VIS browser creature ecology**.

One question gets the **actual existing local deterministic attendant answer**, six materially different, inspectable creatures, a new six-up after SCRAPE, and exact retained ancestry after KEEP. The answer does not change between costumes.

The 47 **named species** are distributed across 15 browser-executable performance families:

Every six-up has **six unique renderer families**, all selected reproducibly, so it cannot present six of the same dressed-up text. Each creature also has a role (ANCHOR, WILDCARD, GHOST, STOMP, FRONTIER, CROSSROADS), deterministic topology vocabulary, materials, motion, palette, species identity, media payload and SHA-256 identity. There are no external services, model inference, generated audio files or videos in this slice.

## The dealer actually does work

- **BIRTH:** seeded six-way diversity.
- **First SCRAPE -> CONVERGE:** visit counters actually choose among underexplored renderer families (the least-visited region is recorded).
- **Second consecutive SCRAPE -> STOMP:** select from formats outside the previous six-up. With 15 supported forms and only six previously shown, this is achievable and testable.
- **Third consecutive SCRAPE -> FRESH_BIRTH:** change neighborhoods again. Scraping never adds a personal preference or negative weight.
- **KEEP:** locks exactly the current candidate digest and family digest as a **local browser-only** continuation decision. Merely previewing a creature has no effect.
- **NEXT after KEEP -> MUTATE:** use the exact kept creature's form as part of the next family.
- **NEXT after two lawful KEeps -> CROSS:** retain both exact ancestors and their distinct formats while dealing the rest of the family. The ordinary user does not choose genetic controls.

These names describe **this new deterministic JS dealer**. This is not an assertion that native Haunted Toaster's real MUTATE/STOMP/CONVERGE/CROSS algorithms ran. Real native invocation requires a separate pinned, source-owned adapter and independent execution tests.

Every structural decision generates a software-only receipt that references the **offered** family and **resulting** family separately. This preserves what was rejected as well as what was proposed. There is a max of 16 accepted human decisions and 15 reproduction rounds per request. The browser maintains only current local state. Each action sends an exact intent list to the original JAR;VIS local endpoint, which replays the history against the original rule-based answer instead of trusting a user-supplied answer or choosing on its own.

## The human has the scissors, not a genome editor

Ordinary controls: **ASK; FOCUS; KEEP; SCRAPE; NEXT; PRINT; EXPORT RECEIPT**. The six cards are full creative phenotypes. There are no user-facing topology, mutation intensity, cross pairing, taste slider, or covert rating controls. Focus is not sent as an authoritative event. KEEP is exact; SCRAPE extinguishes the current family only; neither implies a generalized preference. The receipt viewer is a trapdoor, not a prerequisite for play.

The exported public passport contains question/answer digests, family identity, candidate digests, operations, kept ancestry IDs and receipt digests. The raw question and response text are **not included in the exported passport**, although the live browser and local server temporarily handle them to perform the request. IDs and digests can still be identifying in some contexts; do not put private client or survivor information into a public artifact.

The route uses the existing localhost host/origin checks, anti-CSRF protection, strict JSON request limit, no-store headers, and no external dispatch capability. Six-up birth and each exact verdict are available without CANNON or a network provider. The earlier Cabaret and source-locked evidence-passport experience remain available independently at `/cabaret`.

**Adversarial exercises:** preview without KEEP; SCRAPE 3 times; inspect visit-count frontier and STOMP distance; KEEP one; NEXT; KEEP another; NEXT to CROSS; modify a prior candidate ID and observe HOLD; export a digest-only receipt. The browser preview may be goofy; the embedded local answer should remain identical.

## Limits and next frontier

A hash chain or source digest **is not independent proof of a real human witness**. The browser is not a venue or grant authority. The mocked blueprint is not structural engineering; the signal lamp is not real emergency communication. The species do not run external Suno, manga, image, or video model APIs. Mobile Web Audio / printing / accessibility still deserve hands-on testing.

**Next native crossing:** package one kept creature as an explicit *candidate offer* to the actual Haunted Toaster VisualScore/KEEP renderer, or to an admitted music/manga/video owner. Respect source licensing and author permission, exact model/media lineage and retained proof; never infer KEEP from focus or let rendering imply permission to publish. A second reviewer can then reproduce the exact same fictional content independently.

**Law:** The clown chooses possibility. The human chooses continuation. The receipt retains the truth.
