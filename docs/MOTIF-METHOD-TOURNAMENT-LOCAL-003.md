## Human flow

From the JAR;VIS research branch on a machine with Python 3.11+, Git, Node 20+ and Docker:

    npm test
    npm start

Open http://127.0.0.1:7789/motif.

Under the previously built **Ask MOTIF**, **Let MOTIF Ask**, and **Investigate the Experimental Forest** panels, a fifth panel appears:

**Challenge an existing method.**

Preview checks original public MOTIF source and relevance without running the candidate. The separate **Run the independent transfer tournament** button explicitly runs the genuine original method in Docker. The page then shows the original six synthetic context-shift experiments, a global plurality control, an independently implemented strong role-conditioned classical control, and a clear negative transfer warning. It will never silently interpret a positive native test as an admitted method.

A separate **Save HELD method receipt as JSON** button appears after a successful trial. It downloads a small proof packet into the operator's chosen local location. The packet contains the original source commit, source documents and their hashes, independent fixture/evaluator hashes, full scores, observed regressions and explicit NON-INSTALL/NON-MERGE review requirements. Without clicking Save, nothing is retained beyond the tab. The receiver does not write to any JAR;VIS database, notebook or journal.

The receipt can be reused with the MOTIF CLI, after explicitly placing it on disk:

    python -m motif.method_tournament \
      --receipt /path/to/motif-reviewed-method-held-receipt-003.json \
      --query "reciprocal role conditioned prediction"

This is a read-only preflight: the original branch is still unmerged and the method remains available as a source locator, not as installed code.

## Exact native crossing

GET /api/motif/tournament/state checks on-disk byte-for-byte original source hashes without accessing the network. POST /api/motif/tournament with the existing localhost CSRF protection, explicit query and execute=false invokes the original source-owned **preview** against a fixed public Git repository. execute=true additionally invokes the ORIGINAL fixed, reviewed method and independent comparison harness in a no-network, non-root, read-only container with CPU/memory/PID/time caps. The server allows one trial at a time.

The browser never supplies an arbitrary source URL, branch name, repo command, file path or program. A fixed original role-conditioned prediction method is the ONLY approved execution profile. Unknown queries, mutated source files, changed experimental branch SHA, unavailable Git/Python/Docker, an unrecognized scorecard or failed independent tests result in HOLD.

Python's isolated startup is not a security sandbox. Docker's containment is useful but imperfect. This operator-only interface should not be exposed on a public server or repurposed to execute arbitrary donor code.

## Why the score matters

The original method succeeds against global plurality under a stable synthetic role signal but fails when roles switch or become irrelevant. The strong classical role-conditioned comparator is mathematically equivalent and ties it. This shows genuine *method evaluation, falsification, and nonmerging source retention*, not evidence of a new algorithm or dependable prediction beyond these fictional tasks.

A synthetic report, even with a claimed independent root, is not authenticated human testimony or useful real-world causality. No personal health, legal, community, or experimental human datasets were used. No model weights were trained.
